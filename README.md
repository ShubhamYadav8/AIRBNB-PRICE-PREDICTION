This project focuses on predicting Airbnb listing prices in New York City using machine learning techniques. The model leverages key factors such as location (neighbourhood and geographical coordinates), room type, availability, and host activity to estimate optimal pricing for listings. The dataset used is the Airbnb NYC Listings dataset, which was cleaned and preprocessed by handling missing values, removing pricing outliers, and encoding categorical features. Exploratory Data Analysis (EDA) was performed to understand price variations across neighbourhoods and room types. Two regression models—Linear Regression and XGBoost Regressor—were trained and evaluated using MAE, RMSE, and R² metrics, with XGBoost achieving superior performance. The project provides actionable insights into pricing strategies, helping Airbnb hosts set competitive prices to maximize revenue.
